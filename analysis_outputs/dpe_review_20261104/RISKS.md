# 适配风险与证据边界

- 共享模型和共同目标允许一致性错误；这是静态风险，尚未用当前 checkpoints 验证。
- 异构表示可能提高有用分歧，也可能只增加投影偏差；效果待实验。
- 标量 two-hot 回归不等同于完整分布式 Bellman 学习；不直接移植收敛或误差上界。
- 当前 CDF 距离默认各成员支持相同；异构支持需要新接口及数值验证。
- W1 与 Cramer 的尺度、尾部敏感性不同；跨指标不应复用数值阈值解释性能。
- UCB 中包含均值，不能把它和纯分歧分数视为同一种 uncertainty。
- 当前 physics probe 的误差含 decoder 因素；stage2 是真实状态恢复检查，不验证 critic 校准。
- 分歧和误差都随深度变化会混淆总体相关；需深度分层和匹配 coverage 对照。
- 截断后仍 bootstrap；边界价值可信性需要单独检查。
- 本轮没有运行测试、训练或环境评估；没有发现并确认新的算法 bug，也没有性能提升证据。
